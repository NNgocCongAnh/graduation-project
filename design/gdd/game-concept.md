## Overview
A system designed to automatically generate complex, "closed-room" mystery cases (Unsolved Case Files) that are guaranteed to be solvable, forensically valid, and fair-play.

## Core Pillars
- **Zero Hallucination**: Using a deterministic validator to override LLM inaccuracies.
- **Forensic Validity**: 100% consistency in timestamps, locations, and forensic evidence.
- **Unique Solution**: Every case has exactly one logical path to the culprit.
- **Fair Play**: All necessary clues are provided; no "hidden" information required for the solution.

## High-Level Loop
1. **Generation**: 4 specialized agents create the narrative.
2. **Validation**: A Bipartite Graph solver checks for contradictions and solvability.
3. **Repair**: Localized Patch Repair fixes specific errors without regenerating the whole case.
4. **Export**: Final case files (PDF/Images) are generated for the player.

## Target Audience
- Mystery enthusiasts, detective game players.
- Academic research on Neuro-Symbolic AI and LLM reliability.
