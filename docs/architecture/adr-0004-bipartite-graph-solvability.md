# ADR-0004: Bipartite Graph for Solvability

## Status
Accepted

## Date
2026-10-06

## Summary
Uses a Bipartite Graph to mathematically prove that the case is solvable.

## Decision
Map clues to suspect-alibis. A case is solvable if and only if the graph structure allows a unique matching that identifies the culprit.

## Consequences
- **Positive**: Mathematical proof of solvability.
- **Negative**: High complexity in mapping natural language clues to graph edges.
